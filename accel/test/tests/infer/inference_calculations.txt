We will roughly calculate the expected DMA bytes during decode (let S = prompt size):
- weight loads: 4d^2 for W_Q/K/V/O, 8d^2 for FFN -> 12Ld^2 per step => 12(S-T) * L * d^2
- KV cache: 2LD(S + (S+1) + (S+2) + ... + (T-1) + T), approx = LD(S+T)(S-T)
- total using above params: 12(64) * 4 * 128^2 + 4 * 128 * (128+64) * 64 = 56623104 int4s communicated
- 56623104 int4 / (2 int4 / byte) * 1 clk / byte = 28311552 clk, almost exactly equal to DMA active time!
